# ArtLab

Repositório da marca **ArtLab** (antigo Encanto): identidade visual, coleções de kits e campanhas.

> *Um momento só seu, o resto pode esperar.*

## Estrutura

```
brand/
  tokens.md       cores, fonte e assinatura da marca
  logos/          logos em alta resolução
  colecoes/       prévias das coleções (Contos, Raízes/Brasilidades)
docs/
  colecoes.md     nomes aprovados, paletas e regras de PI
  pendencias.md   próximos passos em aberto
  historico.md    resumo das sessões de trabalho
natal-2026/       campanha Natal 2026 · Noël Botânico
```

## Convenções
- Idioma de trabalho: português do Brasil.
- Nomes de kits **não** citam obras, personagens ou marcas de terceiros.
- Antes de produzir embalagens, pesquisar cada nome no INPI (busca.inpi.gov.br).
- Arquivos vetoriais originais (SVG/AI) devem entrar em `brand/logos/` quando disponíveis.
